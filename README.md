## About me

I'm a backend developer working mainly with **C# and .NET**. My experience includes building business workflows, integrating external services, developing database-backed APIs, and using Redis caching to reduce unnecessary network calls.

I also have a background in computer networks. That makes me interested in what happens outside the application layer too: DNS, connectivity, Linux, container networking, deployment, monitoring, and how services behave when something fails.

At the moment, I'm:

* going deeper into **EF Core 9**, relational modeling, querying, performance, concurrency, and transactions;
* practicing distributed-system building blocks such as service discovery, messaging, resilience, and observability;
* improving my Docker, Linux, CI/CD, and workflow automation skills.
